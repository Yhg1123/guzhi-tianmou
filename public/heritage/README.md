# 开放遗产摄影

两张原始 JPEG 均来自 Wikimedia Commons，来源页标注 CC0 1.0。保留原始字节、可追溯作者与拍摄日期，界面仅通过 CSS 裁切展示。详尽链接、日期、字节数、SHA-256 和处理说明见 `sources.json`。

- `great-wall.jpg`：慕田峪长城，Nicolas Perrault III，2006-07-21。[来源页](https://commons.wikimedia.org/wiki/File:Great_Wall_of_China_July_2006.JPG)。
- `forbidden-city.jpg`：北京故宫，Kaap bij Sneeuw，2018-05-20。[来源页](https://commons.wikimedia.org/wiki/File:Forbidden_City_2018-05_Beijing.jpg)。

这些是历史摄影资料，不保证反映当前状态。单张照片不是三维重建成果，也不构成建筑测量或修缮依据。没有使用生成图片冒充实景摄影。
