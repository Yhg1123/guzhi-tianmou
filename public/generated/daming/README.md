# 含元殿 · 复原构想

本项目自行构建建筑场景、生成一致多视角并在本机训练的 3D Gaussian Splatting。输入不是实拍照片，此模型不是实测复原或考古证据。创作单位没有米制标定，站点坐标仅用于档案关联。

完整 Gaussian 参数、全部生成视角的哈希、相机、创作与训练记录见 source.json；实际训练日志见 training.txt。visual-reference.png 是 AI 生成的视觉设计参考，未作为训练照片，也不是查看器画面。views/ 为同一个本地创作场景的训练输入节选；validation/ 为保留输入及本机模型渲染对照。

代码可重建本地创作场景；不包含借用的第三方成品网格或高斯模型。
