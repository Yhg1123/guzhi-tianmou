# 公众共建 UI 参考与改进方向

研究日期：2026-10-23。目标是改进现有 `community` 页面，帮助游客和当地居民理解影像贡献的价值，再进入照片整理流程。当前阶段为设计预览，尚未应用新的页面布局。

## 已实际查看的参考

### Historic England · Missing Pieces

https://historicengland.org.uk/listing/missing-pieces

已打开页面并捕获实际首屏。首页用横幅摄影、克制导航和图片说明建立场景；正文邀请公众补充照片和故事，并提供参与及地图入口。

适合借鉴：先说明个人照片的价值，再引导参与；摄影与来源说明相邻；任务使用普通人能理解的语言。我们的页面可把照片入口放在明显位置，减少初次进入时的表单压力。

### Europeana

https://www.europeana.eu/en

已打开页面并捕获实际首屏。大图背景上只有清晰的标题、简短说明和突出的搜索框；导航把馆藏、故事和个人集合分开。

适合借鉴：每个区域保持一个主要行动，用标题大小和留白建立层级；通过主题和馆藏组织内容。我们的任务、贡献记录和探访清单已有对应结构，可以在既有路由中改善布局。

## 保留的产品约束

- 保留现有深绿侧栏、浅中性背景和工作台导航。
- 只借鉴布局与交互，不复制参考网站的品牌、摄影作品或代码。
- 保留当前现状影像、老照片、变化记录三种贡献任务及本地原图保存能力。
- 本地试点说明可缩成易读的一行，但必须在主要参与区域可见。
- 不展示虚构的全球人数、机构任务、审核结果、模型完成率或修复进度。
- 示例坐标与遗址必须保留演示标识；未知资料保持未知。
- 贝尔神庙开放案例使用现有真实点云展示，保留 Scott McAvoy / CHEI、Open Heritage 3D 和 CC BY 来源；案例不关联所选中国遗址，不称为训练完成的 3DGS。
- 研究使用意向与公开展示意向仍为独立选择。

## 供选择的设计预览

按主对话中图像的显示顺序选择，避免把概念名称当成实现授权。

- 遗产叙事：通过大标题、开放影像案例与明确的参与入口说明贡献价值。
- 档案发现：让案例浏览与三种参与任务并排呈现，方便从内容进入照片整理。
- 参与工作台：将本地照片选择和记录流程置于主体，拍摄指引作为辅助。

用户选定后，在现有 React 组件中实现；验证本地保存、照片备份、移动布局和导航，再提交仓库。预览中的影像不自动成为文物记录或研究证据，未核验的装饰缩略图不得作为真实遗址照片使用。
