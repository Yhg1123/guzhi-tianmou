# 环境数据总览与现场接入

`#environment` 提供温度/相对湿度点位地图、有效点位数、最高/最低/均值、逐点表格及时间趋势。当前默认请求故宫、慕田峪、莫高窟三个有来源的公开参考位置。其坐标精度待核验；慕田峪是照片的拍摄位置，不是遗产范围中心。

## 公开天气参考

数据来自 [Open-Meteo Forecast API](https://open-meteo.com/en/docs)，为附近天气网格的 2 米气温、相对湿度、10 米风速和降水模型值。它不能代替文物表面、洞窟、展柜或监测站的现场测量。API 返回的网格位置与请求位置一起保存在快照中。模型当前值、过去逐时模型值和未来预报保持区分；未来曲线为虚线。

- 无密钥；当前免费接口用于非商业原型与研究，商业使用需遵守 [服务条款](https://open-meteo.com/en/terms)。数据按 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 署名。
- 当前页每 10 分钟刷新，隐藏标签页暂停；手动刷新可重试。请求超时 20 秒，失败保留同一数据源上次结果。
- 同一页面切换数据源时缓存最近结果。初次请求公开参考点失败时，尝试显示仓库内 2026-10-26 实际导出的 `public/samples/environment-weather-reference.json`，明确标注“离线历史快照 · 非实时”，保留原时次；不会用它填补当前项目或现场数据。超过 1 小时仍排除当前汇总，未来预报以快照时次为基准，重连成功后替换。
- 默认仅发送内置公开坐标。选择“当前项目”后，须点击“加载项目天气”才将项目经纬度发送至 Open-Meteo；每次最多 30 个点位。
- 所有显示时间均为北京时间；原始快照用 Unix 毫秒时间，降水聚合时段为记录中的 `interval` 秒。
- 未知指标显示 `—`；0 °C、0% 和零降水是有效数值。超过 1 小时的数据标记过期，排除当前汇总并在地图中显示灰色。地图只着色离散点，不插值温度场，不生成没有依据的文物病害风险。

## 现场观测 JSON

“现场观测接入”没有默认传感器。可导入不超过 2 MB 的 JSON，验证后独立保存在 IndexedDB 的 `heritage-environment-sensors-v1`。也可输入返回同一格式的只读 HTTP(S) 服务地址。服务应允许本网页跨域读取；浏览器不发送 cookies 或请求来源，凭据由服务端处理，不要在 URL 中放密钥。远程结果保存在当前页面内存，导出快照后才能离线留存。

以下是格式说明，数值是虚构的，不能当成现场资料：

```json
{
  "schema": 1,
  "source": "机构 / 设备编号 / 校准记录；此处为格式示意",
  "units": { "temperature": "°C", "humidity": "%" },
  "readings": [
    {
      "siteId": "替换为当前点位ID",
      "timestamp": "2026-01-01T08:00:00+08:00",
      "temperature": 20.1,
      "humidity": null
    }
  ]
}
```

`siteId` 必须与项目或公开参考点的 ID 对应，可从项目/环境导出文件取得。读取 1–5,000 条记录，时间须包含 `Z` 或时区偏移，不能超过当前时间 5 分钟；温度范围 -90–70 °C，湿度 0–100%。每条至少一个有效指标，缺失值用 `null`，不填 0。同一测点同一时次不得重复。每个测点采用最新一条记录，历史按时间排序；较早记录的湿度不会填补最新记录的缺失湿度。未知 ID 单独提示，不计入当前集合的地图与汇总。数值范围只用于格式检查，不是文物适宜性或风险阈值。

空白模板在 `public/templates/environment-sensor-example.json`，不带虚构测值，因此直接导入会提示记录为空。请按实际采集资料填写。文件无效时不会覆盖原本地观测。天气快照明确标记 `weather_model_not_onsite_sensor`，拒绝当作现场传感器记录导入。

## 备份与后续部署

“导出快照”包含请求点位、单位、来源、获取时间、网格位置及已取得的逐时记录。现场快照同时输出 `readings`，可重新导入。环境记录不在项目 JSON 备份中，原始数据应由采集机构另行保留。当前实现适配数据格式与可视化，不代表已连接真实设备，也不代表具有连续历史数据库。

正式接入需要：现场设备和校准资料、监测位置与档案 ID 的映射、可持续的数据服务、历史数据库、访问权限及设备状态管理。保护阈值和告警规则须由对应文物材质、环境条件和专业机构要求确定，不能套用任意温湿度阈值。
