# 大明宫含元殿 · 本机生成的高斯复原构想

用户明确允许生成多角度素材，并把清晰度、完整空间和自由旋转作为当前展示目标。本次成果采用**同一个本地创作的三维建筑场景 → 一致的多角度渲染 → 实际 Gaussian 优化**，避免用独立生成、结构互相矛盾的图片训练出重影，也不使用他人的成品高斯或外站播放器。

这是建筑复原构想。生成视图不是现场照片，构件、比例、布局和创作单位都不能当作考古测量或修复依据。项目原有的大明宫陈列照片、来源许可、单图预览及用户导入模型继续保留；模型与项目坐标的关联用于档案导航，不代表三维地理配准。

## 创作内容与参考

场景由 `scripts/build-daming-concept.py` 自行构建，包括重檐主殿、两侧楼阁、转折连廊、三层台基、阶梯、石栏杆、柱础、木构支承、格栅门窗及带实体瓦垄和屋脊的曲面屋顶。未导入第三方成品网格。

视觉设计参考由 Image Gen 生成，记录在 `visual-reference.png`。它只用于造型和材料方向，不是训练输入、现场照片或浏览器模型截图。实际训练输入均由一个确定的 Blender 场景生成，因此相机、正反面、遮挡与构件结构彼此一致。

历史身份参考[文化主管部门关于含元殿的介绍](https://www.mct.gov.cn/whzx/whyw/201112/t20111201_707767.htm)，以及 [Commons 大明宫影像目录](https://commons.wikimedia.org/wiki/Category:Daming_Palace)中的形象资料。这些参考不能使本次创作成为经核验的历史原状；没有把整个遗址误写为一座保存至今的完整宫殿。

## 一致多视角与本机训练

- Blender 5.1.2 在本机生成 **104 个 RGBA 视角**：三组高度的全周环绕、高位俯视、底部视角及建筑近景。每张图保留 SHA-256、文件长度、相机内参和完整相机到世界矩阵。
- 将 Blender Z-up 坐标统一旋转为查看器使用的 Y-up；相机与初始化几何使用同一个变换。初始化点从本项目创作的几何表面按面积和材质权重抽样，**不是从现场摄影匹配得到**。
- 每第八个视角留出比较，**91 个用于训练，13 个用于比较**。全部初始几何来自同一创作场景，因此保留视角的图像指标不是独立几何精度评估。
- 使用固定版本的 Brush 0.3.0 原生引擎在 RTX 3050 Laptop GPU 上实际完成 **24,000 步**优化，degree 1 球谐颜色。最终选择第 24,000 步的完整输出，含 **207,454 个高斯、19,086,420 字节**；参数、时间、检查点和输出哈希见 `training.json` 和原始日志。
- 打包脚本按保留视图的前景图像一致性选择检查点，计算方法为 alpha ≥250 区域的 RGB MSE/PSNR。原生整图指标同时保留。图像一致性不能替代正、背、侧、俯视和近景的直接画面检查。
- 导出保留完整训练 PLY 的位置、各向异性尺度、旋转、透明度、DC 与一阶 SH；未把模型退化成不透明等大小 RGB 点或单图深度表面。

## 文件与复现

开发期间的完整场景、全部生成视图、初始化及检查点保存在被忽略的 `qa/daming-concept/`。公开包位于 `public/generated/daming/`，包含训练模型、完整来源、实际日志、生成输入节选及保留视角对照。前端轻量索引为 `src/damingConceptCatalog.json`。

```powershell
blender --background --factory-startup --python scripts/build-daming-concept.py -- --render-views --resolution 960
node scripts/train-daming-concept.mjs
./qa/model-runtime/Scripts/python.exe scripts/package-daming-concept.py
```

原生训练器的安装与固定哈希见 `scripts/install-local-trainer.ps1`。不要混用旧运行；训练脚本遇到已有检查点会停止，以保留旧数据。训练脚本不向服务端提交素材。

打包并不自动通过展示验收。检查记录须与最终原始模型的 SHA-256 一致，逐项核对结构、旋转/新视角、浮点和“大明宫建筑构想”的主体范围后，才能进入正常项目展示。待检查或哈希不符的模型不会自动替换遗址档案。

本次原始模型 SHA-256 为 `370cdca9a9ce46cab3ade441282bc42fe61ce881fe55154cfa205c92b244e1bf`。已直接检查该文件在页面中的正面、背面、左右侧、完整屋顶及主殿近景，验收范围为建筑构想的视觉展示，不能解释为历史形制或测绘验收。浏览器检查另验证了实际画布变化、拖拽与键盘导航、全屏退出、390px 布局、其他遗址隔离及导入文件刷新后的优先显示与完整保留。

## 展示与资料隔离

大明宫的默认三维页在模型通过检查后直接显示本地高斯，提供自由环绕、平移、缩放、背面/侧面/俯视预设及主殿、侧阁、台基细节入口，全屏支持 Escape 与焦点返回。真实遗址影像在单独页签保留。

绑定按站点 ID、原始坐标和清理后的名称核对。其他遗址、修改坐标的同名记录及未知站点不使用该模型。已存在的用户导入模型优先；复原构想可以通过独立页签主动打开，不删除或覆盖导入文件。

社区投稿与原片整理仍不构成通用自动训练服务。本次创作素材训练流程不能被表述成任意游客照片已经自动完成云端重建，也不能作为对现场文物安全或修复方案的判断。
