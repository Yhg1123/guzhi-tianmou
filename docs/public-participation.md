# 文旅探访与公众数字守护方案

## 产品定位

让游客、当地居民和文保工作者围绕同一处遗产协作：游客认识遗址并采集现状，居民补充老照片与记忆，专业人员审核并使用资料，平台展示可追溯的成果。公众参与数字记录、历史线索整理和持续观察；实体修缮由具备相应条件的专业机构负责。

建议对外名称为“古址天眸 · 全民数字守护”，参与入口为“公众共建”。第一阶段从一处管理方愿意合作、可以合规拍摄的遗产点开始，验证照片是否真的被采用，再扩大规模。

## 已实现的本地试点

- 三类任务：补充现状影像、寻找老照片、记录时间变化。任务为设计示例，未代表景区发出采集委托。
- 探访清单，与遗址名录联动；未经核验的演示坐标不提供旅游导航。
- 实际照片原图、缩略图和分辨率登记；SHA-256 精确重复检查，不伪称已经识别模糊照片、自动求出拍摄机位或完成模型补洞。
- 拍摄方向、日期、署名、故事与疑点登记。日期可留空，方向可标为不确定。
- 提供资料的权利确认、非商业研究保护用途意向、可选公开展示意向分别记录。当前是本地流程试点，未签署线上投稿协议。
- 本地贡献列表、刷新恢复、原图下载、说明清单导出。清单不包含图像；项目 JSON 备份也不包含本页原图。

照片仅保存在此设备 IndexedDB，不上传，不供其他人查看。清除浏览器数据会丢失存档，原始照片仍应另行备份。单份最多 12 张、每张不超过 20 MB、合计不超过 60 MB，本地资料总量限制 150 MB。

## 建议优先建设的六个线上功能

| 功能 | 游客看到什么 | 项目方获得什么 |
| --- | --- | --- |
| 公开采集任务 | 需要补拍的构件、可到达机位、允许拍摄区域与拍摄示例 | 符合真实缺口的素材，而非大量重复照片 |
| 景点入口与导览 | 景区二维码、遗产故事、已核验开放信息、参与任务入口 | 让文旅探访转化为可持续的保护参与 |
| 照片资料征集 | 断点续传、权利与用途选择、提交编号 | 原始文件、来源与拍摄批次 |
| 老照片与记忆地图 | 时间不确定也能投稿、同一景观的历史故事 | 历史状态线索与可核验出处 |
| 专业审核与素材反馈 | 已接收、需补充、已采用及具体反馈 | 可筛选、可追溯且权限清晰的资料库 |
| 成果与贡献回访 | 某批照片用于哪个模型版本、时间对比与贡献署名 | 知识传播与长期志愿者关系 |

“缺口图”应来自管理员标注或真实相机覆盖分析。投稿张数、拍摄方向标签、模型覆盖率和文物修复进度是不同指标，不能互相替代。

## 一条实际参与路径

游客在景区扫码 → 了解遗产故事 → 领取允许范围内的采集任务 → 按指引保留原图 → 选择用途并上传 → 收到资料编号 → 管理方审核 → 获得补拍建议或采用反馈 → 看到注明来源和版本的数字成果。

可以增加“守护足迹”和贡献证明，依据被审核采用的资料与具体工作记录发放，避免以照片数量或上传次数制造竞争。馆校合作、亲子研学、当地居民口述史都可以沿用这条流程；不必一开始做排行榜、商城或复杂积分体系。

## 正式多人上线需要接通什么

1. **真实接收方与任务管理**：每个项目有负责机构、任务范围、采集规范、联系与反馈渠道。
2. **账号与角色**：参与者只能管理自己的投稿；项目审核人只处理授权项目；模型发布由指定人员完成。
3. **接收原图**：对象存储保存文件，数据库保存投稿、照片哈希、项目关联与用途版本。浏览器使用短期上传凭据，文件校验与配额在服务端重做。
4. **审核与隐私处理**：上传先进入私有待审核区；公开展示使用处理后的副本，剥离不应公开的定位元数据，并处理可识别人脸等信息。原图访问与公开展示分开授权。
5. **真实处理队列**：按遗址、时间、构件和拍摄批次分组；先检查匹配与相机位姿，再进行摄影测量或 3DGS 训练。不同年代、脚手架与植被变化不能不加区分地混训。
6. **来源与版本**：每个发布模型保留所用照片 ID、处理参数、审核人、质量说明和历史版本，能说明公众贡献带来了什么。
7. **撤回与备份**：保留投稿者查看与申请撤回资料的入口，处理原图与已发布成果的关联，建立备份和容量监控。

建议状态流为：草稿 → 上传中 → 待审核 → 需补充 / 退回 / 接受归档 → 纳入处理批次 → 发布成果引用。只有收到相应服务端结果时才变更状态。

## 与现有系统的结合

- 遗址地图：展示经管理方确认的参与点与任务入口，敏感位置按公开范围处理。
- 遗址档案：连接故事、采集任务、历史照片和数字成果。
- 保护评估：把公众观察作为待核验线索，专业意见与公众描述分开保存。
- 三维档案：关联审核后的照片批次与模型版本；公众可看成果与贡献说明，不能直接改写模型档案。
- 数据中心：提供项目与照片资料的独立备份，清楚区分清单、原图和派生模型。

## 可参考的既有实践

- [Rekrei](https://www.rekrei.org/about)：收集专家、游客与公众照片，通过摄影测量帮助记录受损或消失的遗产。
- [Historic England Missing Pieces](https://historicengland.org.uk/listing/missing-pieces)：公众为遗产名录补充照片与故事，连接地方记忆、到访体验和保护工作。
- [Tirtha 研究](https://arxiv.org/abs/2308.01246)：研究面向遗产的照片众包与三维建模流程，可作为处理管线的参考；不等于本系统已接入其后台。

建议首个试点成功标准：管理方提出了真实资料需求；公众能完成一次投稿；审核人能够给出可理解的反馈；至少一批素材确实被用于档案或数字成果。不要用投稿量替代是否有用。
